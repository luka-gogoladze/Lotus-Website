# LOTUS — Landing Page & Web Interface
**სქილვილის Front-end პრაქტიკული პროექტი (06.1.1.9)**

იხილეთ პროექტის სრული საგამოცდო დოკუმენტაცია, სამუშაო გეგმა, რისკების მატრიცა, ტექნოლოგიური სტეკი და პრეზენტაციის გეგმა პროექტის მთავარ `README.md` ფაილში: [../README.md](../README.md).

### სწრაფი გაშვება:
გახსენით `index.html` ნებისმიერ ბრაუზერში ან გამოიყენეთ VS Code Live Server.

### ძირითადი კომპონენტები:
* `index.html` — სემანტიკური HTML5 მარკირება (სლაიდერი, სუნთქვის ვიჯეტი, ფორმა, მოდალი)
* `style.css` — CSS3 დიზაინის სისტემა (Dark Luxury Zen, Glassmorphism, Grid/Flexbox რესპონსივობა)
* `app.js` — Vanilla JavaScript ფუნქციონალი (სლაიდერის მართვა, სუნთქვის ძრავა, რეალურ დროში ფორმის ვალიდაცია, მოდალი, აკორდეონი, Toast)
